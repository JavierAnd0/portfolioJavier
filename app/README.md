# Portfolio — Javier Andrade

Persona 5–themed portfolio built with React 19, TypeScript, Vite and Tailwind. Bilingual (EN/ES).

## Development

```bash
cd app
npm install
npm run dev      # dev server
npm run build    # type-check + production build
npm run words    # regenerate SVG lettering (design/words/raw -> words.generated.ts)
```
